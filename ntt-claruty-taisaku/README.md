# 入社試験対策 学習アプリ(国語・数学・英語)

これは、就労支援施設等で得られた「NTTクラルティの入社試験には国語・数学・英語がある」という
情報をもとに、**出題範囲や難易度が公表されていない採用試験に備えるための、段階的な学習アプリ**です。

**重要なお断り**: このアプリの問題は「NTTクラルティの実際の過去問」ではありません。実際の過去問・
出題範囲・難易度は公表されておらず、不明です。このアプリは「中学基礎〜高校卒業程度」を想定して
作成した、あくまで練習用の対策教材です。

Windows PCのブラウザ(Chrome / Edge)だけで動きます。インストール作業やアカウント登録、
インターネット接続は不要です(初回に開くときだけファイルの場所が分かれば十分です)。

---

## 1. どのファイルを開けば起動するか

このフォルダの中にある **`index.html`** をダブルクリックして、ブラウザ(Chrome推奨、Edgeも可)
で開いてください。それだけでアプリが起動します。

- フォルダごとどこに置いても構いません(USBメモリやデスクトップなど)。
- サーバーを立てたり、コマンドを打ったりする必要は一切ありません。
- 一度開けば、以後は完全にオフラインで動作します(外部の通信は一切行いません)。

もし「ホーム画面」が表示されず真っ白になってしまう場合は、`index.html`・`style.css`・`app.js`・
`features.js`・`data-kokugo.js`・`data-math.js`・`data-eigo.js` の7つのファイルが
すべて同じフォルダの中に揃っているか確認してください。1つでも欠けると正しく動作しません。

---

## 2. 学習データがどこに保存されるか

学習の記録(正解・不正解の履歴、診断結果、追加した問題など)は、**ブラウザの「localStorage」**
という場所に、この端末・このブラウザの中だけに保存されます。

- インターネットには一切送信されません。
- 保存されるブラウザ・保存場所のキー名は `ntt_claruty_app_v1` です。
- 別のパソコンやブラウザで `index.html` を開いても、記録は引き継がれません(端末ごとの記録です)。
- ブラウザの「閲覧履歴・キャッシュの削除」を行うと、学習記録も消えてしまう場合があるので注意してください。
  大事な記録は、後述の方法で定期的にバックアップすることをおすすめします。

## 3. 問題を追加する方法

ホーム画面の **「問題管理」** から、2通りの方法で問題を追加できます。

### 方法A: フォームから1問ずつ追加する

1. 「問題管理」を開く。
2. 左側のフォームに、科目・分野・レベル・出題形式(4択/記述)・問題文・選択肢(または正解)・
   解説を入力する。
3. 数学の問題であれば、「途中式・計算ステップ」欄に1行1ステップで計算過程を入力すると、
   回答後の解説画面に途中式が表示されます。
4. 「追加する」を押すと、右側の一覧に追加されます。

### 方法B: JSONファイルをまとめてインポートする

あらかじめ次のような形式でJSONファイルを用意すると、一度に大量の問題を追加できます。

```json
[
  {
    "id": "my_question_001",
    "subject": "math",
    "category": "割合",
    "level": 2,
    "type": "choice",
    "question": "5000円の20%はいくらですか?",
    "choices": ["500円", "1000円", "1500円", "2000円"],
    "answer": "1000円",
    "explanation": "5000 × 0.20 = 1000 です。",
    "steps": ["5000 × 0.20 = 1000"]
  }
]
```

- `subject` は `kokugo`(国語)・`math`(数学)・`eigo`(英語)のいずれか。
- `level` は1〜5(1:基礎 〜 5:採用試験想定)。
- `type` が `"choice"` の場合は `choices`(4つ)と、その中の1つと完全に一致する `answer` が必要です。
- `type` が `"input"` の場合は `choices` は不要で、`answer` に正解の文字列を入れます。別解を
  許容したい場合は `"acceptableAnswers": ["別解1", "別解2"]` を追加できます。
- `steps`(途中式)と `id` は省略可能です(`id`を省略するかIDが重複する場合は自動的に採番されます)。

「問題管理」画面の **「JSONをインポート」** ボタンからこのファイルを選択すると、まとめて追加されます。

---

## 4. バックアップ方法

「問題管理」画面の上部にある2つのボタンから、問題データをJSONファイルとして書き出せます。

- **「追加分をエクスポート」**: 自分で追加・編集した問題だけを書き出します(バックアップや、
  他の端末に問題を引き継ぐ場合に使用)。
- **「全問題をエクスポート」**: 最初から入っている問題と追加分をすべて合わせて書き出します。

学習の記録(正誤の履歴や診断結果)そのものをバックアップする機能は現時点ではありません。
重要なデータのバックアップが必要な場合は、開発者ツールの「アプリケーション」タブから
localStorageの `ntt_claruty_app_v1` の値をコピーして保存する、といった方法になります
(この操作は多少専門的な知識が必要です)。

---

## 5. 初期化方法(学習記録を全部消してやり直す)

「学習履歴」または「問題管理」画面の一番下にある **「学習データをすべて初期化する」** ボタンを
押してください。2回確認のダイアログが出た後、以下がすべて削除されます。

- これまでの正解・不正解の記録
- 診断テストの結果
- 学習履歴(グラフ・表)
- 自分で追加した問題

**最初から入っている568問の問題そのものは消えません**(データファイルの中身なので、初期化しても
また使えます)。

## アプリの構成・機能概要

### 学習の流れ

1. **実力診断テスト**(国語・数学・英語それぞれ12問、合計36問)を受けて、分野別の正答率と
   「中学1年相当:十分」のような学年別の到達度を確認する。
2. **今日の学習**で、苦手分野・未回答の問題・復習期日が来た問題をバランスよく出題(最大20問)。
3. **弱点克服**で、正答率が低い分野(5問以上回答した上で正答率60%未満)を重点的に復習する。
   まだ回答数が少ない分野については「判定にはもう少し回答が必要です」と表示され、
   早すぎる断定はしません。
4. **分野別学習**で、科目・分野・レベルを自分で指定して学習する。
5. **間違えた問題**で、間違えた問題そのものと、同じ分野の類題をあわせて復習する。
6. **模擬試験**(短時間15問/標準45問/科目別20問、制限時間ON/OFF可)で総合力を確認する。
   結果画面には、総合点・科目別得点・分野別正答率・所要時間・間違えた問題・おすすめの復習分野
   が表示される。
7. **学習履歴**で、これまでの学習回数・総問題数・正答率・学習時間と、直近の正答率の推移
   (簡易グラフ)を確認できる。

### 収録問題数

- 国語: 116問(漢字の読み・書き、語彙、類義語、対義語、四字熟語、慣用句、敬語、文法、
  文章の並べ替え、短文読解、長文読解、要旨、内容一致、適切な表現)
- 数学: 302問(四則演算〜正負の数などの基礎、割合・速さ・金額計算などの実務計算、
  一次方程式〜図形などの中学数学、二次関数・場合の数などの高校基礎、
  仕事算・損益算・鶴亀算などの複合的な文章題)
- 英語: 150問(be動詞・一般動詞などの基礎文法から、現在完了・受動態・比較・語順並べ替え・
  長文読解まで、中学英語を厚めに収録)
- **合計568問**(いずれも「100問以上/科目」「合計300問以上」という目標を満たしています)

数学の問題の多くは、Pythonスクリプトで「乱数でパラメータを生成→そのパラメータから正解も
機械的に計算する」という方式で作成しており、計算問題としての正確性を構造的に保証しています。
国語・英語の問題はすべて手作業で1問ずつ作成し、内容を確認しています。

### ファイル構成

```
index.html       画面のHTML(ホーム・診断・クイズ・結果・履歴・問題管理などをJSで切り替え)
style.css        スタイル(PC幅を活かしつつ、文章が伸びすぎない最大幅を設定。スマホ対応も含む)
app.js           共通処理(保存・出題エンジン・ホーム画面・進捗計算)
features.js      診断テスト・模擬試験・学習履歴・問題管理の画面ロジック
data-kokugo.js   国語の問題データ(116問)
data-math.js     数学の問題データ(302問)
data-eigo.js     英語の問題データ(150問)
```

## 動作確認について

開発時に、Chromiumブラウザによる自動操作テストで以下を確認済みです。

- 診断テスト(36問)の実施と、分野別正答率・学年別到達度の判定結果表示
- 今日の学習・分野別学習・弱点克服・間違えた問題の各モードでの出題
- 弱点克服モードでの「データ不足」判定メッセージと、実際の苦手分野検出の両方
- 模擬試験(短時間/標準/科目別)の実施と、科目別・分野別の詳細な結果表示
- 数学の解説での「途中式」の表示
- 問題管理での問題の追加・編集・削除、JSONのインポート・エクスポート
- 学習履歴の表示とグラフ描画、データの初期化
- 画面幅375px(スマホ)・768px(タブレット)・1440px(PC)での横スクロールが発生しないこと
- JavaScriptエラーが発生しないこと

## 既知の制限

- 問題管理画面から追加できるのは「新しい問題の追加」までで、最初から入っている568問の
  内容を画面上で直接編集する機能はありません(編集したい場合は `data-*.js` ファイルを
  直接テキストエディタで編集してください)。
- 学習記録そのもの(正誤履歴)のエクスポート/インポート機能はありません(問題データの
  エクスポート/インポートのみ対応)。
- 複数端末・複数ブラウザ間での学習記録の自動同期はありません(端末ごとに記録が分かれます)。
