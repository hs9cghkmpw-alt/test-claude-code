# 高校勉強アプリ(国語・数学・英語)

スマホ1台で完結する、個人利用向けの学習用PWA(Progressive Web App)です。
サーバーやアカウント登録は不要で、学習記録はスマホ内(ブラウザのlocalStorage)だけに保存されます。

## 機能

- 国語・数学・英語、それぞれ高校レベルのサンプル問題(4択クイズ)
- 間違えた問題を自動で「苦手」として記録し、一定期間後に復習に出題(簡易的な間隔反復学習)
- 科目ごとの正答率・習得状況を確認できる統計画面
- オフライン動作(ホーム画面に追加するとアプリのように使える)

## スマホで使い始める(推奨: ホーム画面に追加してオフライン利用)

1. このリポジトリのファイル一式(`index.html`, `style.css`, `app.js`, `data.js`, `manifest.json`, `sw.js`, `icons/`)を、まずはPCなどでどこかのWebサーバーにアップロードするか、後述の「ローカルで動作確認する」方法でスマホから開きます。
2. iPhone(Safari)の場合: 共有ボタン → 「ホーム画面に追加」。
   Android(Chrome)の場合: メニュー → 「ホーム画面に追加」または自動で出る「アプリをインストール」の案内。
3. 一度読み込めば、Service Workerがファイルをキャッシュするので、以後は機内モードでも起動できます。

## ローカルでの動かし方(このアプリだけで完結、開発・動作確認用)

このアプリはビルド不要の素のHTML/CSS/JSなので、PC上で以下のように簡易サーバーを立てて、同じWi-Fi内のスマホから確認できます。

```bash
# このフォルダで実行
python3 -m http.server 8000
```

PCのIPアドレス(例: 192.168.1.10)を確認し、スマホのブラウザで
`http://192.168.1.10:8000` を開くと、同じWi-Fi内から動作確認できます。
（`file://` で直接HTMLを開くだけでも一覧の動作はしますが、Service Worker(オフライン対応)は
`http://` 経由でないと登録できないブラウザが多いので、簡易サーバー経由を推奨します。)

動作確認ができたら、GitHub Pagesなど無料の静的ホスティングにアップロードすれば、
自分専用のURLとしてどこからでも(オフライン化した後は圏外でも)使えるようになります。

## 問題を追加・編集する

問題データはすべて `data.js` に入っています。科目ごとに配列があるので、
同じ形式でオブジェクトを追加するだけで問題を増やせます。

```js
{
  id: "kk-19",              // 科目内でユニークなID
  category: "漢字",          // 表示用のカテゴリ名
  question: "問題文",
  choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  answer: 0,                 // 正解のchoices配列内インデックス(0始まり)
  explanation: "解説文"
}
```

`id` を変えずに `question` や `choices` を編集すると、その問題の学習履歴(習得状況)は
引き継がれます。`id` を変えると新しい問題として扱われます。

## 学習記録の仕組み(簡易版Leitner方式)

- 各問題には「箱(box)」という習熟度レベル(0〜5)があります。
- 正解すると箱のレベルが1つ上がり、次に出題される(復習対象になる)までの間隔が長くなります
  (1日後 → 3日後 → 7日後 → 14日後 → 30日後)。
- 不正解になると箱はレベル0に戻り、「苦手」として記録され、次回以降の復習対象になります。
- 箱のレベルが4以上になった問題は「習得済み」として統計画面でカウントされます。
- 記録はすべて端末のlocalStorageに保存されます。ブラウザのデータを消去したり、
  別のブラウザ・別の端末で開いたりすると記録は引き継がれません(統計画面の
  「記録をリセット」も同じ仕組みで、ローカルのデータを消去します)。

## ファイル構成

```
index.html   画面のHTML(ホーム/クイズ/結果/統計の4画面をJSで切り替え)
style.css    スタイル
app.js       アプリのロジック(出題・採点・復習スケジューリング・画面遷移)
data.js      国語・数学・英語の問題データ
manifest.json PWA設定(アプリ名・アイコン・起動時の見た目)
sw.js        オフラインキャッシュ用のService Worker
icons/       ホーム画面アイコン用のPNG画像
```
