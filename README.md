# 高校勉強アプリ(国語・数学・英語)

スマホ1台で完結する、個人利用向けの学習用PWA(Progressive Web App)です。
サーバーやアカウント登録は不要で、学習記録はスマホ内(ブラウザのlocalStorage)だけに保存されます。

## 機能

- 国語・数学・英語、それぞれ高校レベルの4択クイズ(問題は随時追加中)
- 間違えた問題を自動で「苦手」として記録し、一定期間後に復習に出題(簡易的な間隔反復学習)
- 科目ごとの正答率・習得状況を確認できる統計画面
- オフライン動作(ホーム画面に追加するとアプリのように使える)

## 全体の流れ(まずはここだけ読めばOK)

このアプリは「ビルド不要のHTML/CSS/JSファイルの集まり」です。難しいことをしなくても、
以下の流れでスマホに入れて使えるようになります。

```
① GitHub上にコードがある(このリポジトリ)
        ↓
② どこかで「動かせる状態」にする ← ここが2択(下のA・Bどちらか)
        ↓
③ スマホのブラウザでアプリのURLを開く
        ↓
④ 「ホーム画面に追加」する
        ↓
⑤ 以後はアイコンをタップするだけでアプリのように使える(オフラインでもOK)
```

②の「動かせる状態にする」方法には2つあります。迷ったら **方法A(GitHub Pages)** が
一番簡単で、パソコンを常につけておく必要もありません。

| | 方法A: GitHub Pages | 方法B: 自分のPCでサーバー |
|---|---|---|
| 難易度 | かんたん(設定は最初の1回だけ) | ややかんたん(PCが必要) |
| 使える場所 | ネットがあればどこでも(外出先もOK) | 自分のPCと同じWi-Fiの中だけ |
| PCを常に起動しておく必要 | 不要 | 動作確認する間だけ必要 |
| 公開範囲 | インターネット上に公開される(URLを知っている人はアクセス可能) | 自分のWi-Fi内だけ |

**プライバシーについて補足**: 公開されるのはこのアプリの「問題データ」や「見た目」だけです。
あなたが何問正解したか・どこが苦手かといった学習記録は、常にスマホ本体の中(ブラウザのlocalStorage)
にしか保存されず、GitHubやインターネット上には一切送信されません。とはいえURLが漏れれば
誰でもクイズ自体は閲覧できるので、それが気になる場合は方法Bを選んでください。

## 方法A: GitHub Pagesで公開してスマホから使う(おすすめ・一番簡単)

### A-1. GitHub Pagesを有効にする(最初の1回だけ、PCのブラウザで作業)

1. PCのブラウザで、このリポジトリのページを開きます。
   `https://github.com/hs9cghkmpw-alt/test-claude-code`
2. 上部タブの **「Settings」**(歯車のアイコン)をクリックします。
   ※ Settingsタブが見えない場合は、リポジトリの管理者権限があるアカウントでログインしているか確認してください。
3. 左側メニューの一番下あたりにある **「Pages」** をクリックします。
4. 「Build and deployment」という項目の **「Source」** が `Deploy from a branch` になっていることを確認します。
5. その下の **「Branch」** のプルダウンから、ブランチ `claude/high-school-study-app-itcbb5` を選び、
   フォルダは `/ (root)` のままにして **「Save」** をクリックします。
   (mainブランチにはまだアプリ本体が入っていないので、必ずこのブランチを選んでください)
6. 数十秒〜数分待つと、ページ上部に「Your site is live at
   `https://hs9cghkmpw-alt.github.io/test-claude-code/`」のように表示されます。
   これがあなた専用のアプリのURLです。ブックマークしておきましょう。

### A-2. スマホでアプリを開く

スマホのブラウザ(iPhoneはSafari、AndroidはChromeを推奨)で、A-1で確認したURLを開きます。

```
https://hs9cghkmpw-alt.github.io/test-claude-code/
```

ホーム画面が表示されれば成功です。

### A-3. ホーム画面に追加してオフライン対応にする

- **iPhone(Safari)の場合**: 画面下(または上)の共有ボタン(四角から矢印が上に出ているアイコン)を
  タップ → 下にスクロールして **「ホーム画面に追加」** を選択 → 右上の「追加」をタップ。
- **Android(Chrome)の場合**: 右上の「⋮」メニュー → **「ホーム画面に追加」**、または自動で
  表示される「アプリをインストール」の案内をタップ。

これで、ホーム画面にアプリのアイコンが追加されます。一度開いておけば、Service Workerが
ファイルを端末内にキャッシュするので、以後は機内モードや電波のない場所でも起動できます。

### A-4. 問題が新しく追加された時はどうなる?

このアプリは「まずネットから最新の問題データを取りに行き、オフラインの時だけ保存済みのデータを使う」
という仕組みになっています。そのため、**電波が入る状態でアプリを開けば、特別な操作なしに
自動的に最新の問題に更新されます**。何も表示されない・変化がない場合は
[トラブルシューティング](#トラブルシューティング)を確認してください。

## 方法B: 自分のPCだけで動かす(ネットに公開したくない場合)

### B-1. コードを手元に取得する

どちらか好きな方法で構いません。Gitに慣れていなければ①がおすすめです。

**① ZIPファイルとしてダウンロードする(Git不要・一番簡単)**

1. リポジトリページ `https://github.com/hs9cghkmpw-alt/test-claude-code` を開く。
2. ブランチ選択(左上、「main」と書かれているところ)をクリックし、
   `claude/high-school-study-app-itcbb5` に切り替える。
3. 緑色の **「Code」** ボタン → **「Download ZIP」** をクリック。
4. ダウンロードされたZIPファイルをダブルクリックして解凍する。

**② git cloneする(ターミナルに慣れている人向け)**

```bash
git clone https://github.com/hs9cghkmpw-alt/test-claude-code.git
cd test-claude-code
git checkout claude/high-school-study-app-itcbb5
```

### B-2. 動かす(2通りのやり方)

**① VS CodeのLive Server拡張機能を使う(ターミナル操作なし・初心者向け)**

1. [Visual Studio Code](https://code.visualstudio.com/)をインストールする(無料)。
2. VS Codeで、B-1で取得したフォルダ(`test-claude-code` フォルダ)を開く。
3. 左側の拡張機能アイコンから **「Live Server」**(Ritwick Deyさん作)を検索してインストール。
4. `index.html` を開いた状態で、右下の **「Go Live」** をクリック(または `index.html` を
   右クリックして「Open with Live Server」)。
5. 自動的にブラウザが開き、`http://127.0.0.1:5500` のようなURLでアプリが表示されます。

**② ターミナルで簡易サーバーを立てる(Pythonが入っている人向け)**

```bash
# test-claude-code フォルダの中で実行
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くと確認できます。

### B-3. スマホから同じWi-Fi経由でアクセスする

1. PCとスマホを**同じWi-Fiネットワーク**につなぐ。
2. PCのIPアドレスを調べる。
   - Mac: 「システム設定」→「Wi-Fi」→ 接続中のネットワークの詳細
   - Windows: コマンドプロンプトで `ipconfig` を実行し「IPv4 アドレス」を確認
   - 例: `192.168.1.10` のような数字
3. スマホのブラウザで `http://192.168.1.10:8000`(Live Serverの場合はポート番号を `5500` などに読み替え)を開く。
4. 表示されたら、A-3と同じ手順で「ホーム画面に追加」する。

※ `file://` としてHTMLファイルを直接スマホやPCで開くだけでも画面は表示されますが、
Service Worker(オフライン対応)は `http://` や `https://` 経由でないと登録できない
ブラウザが多いため、簡易サーバー経由をおすすめします。

## 問題が更新された時に最新版を取り込む方法

- **方法A(GitHub Pages)の場合**: 何もしなくてOKです。電波が入る場所でアプリを開けば、
  Service Workerが自動的に最新のdata.jsを取りに行きます。
- **方法B(自分のPC)の場合**:
  - ZIPでダウンロードした人 → もう一度「Download ZIP」をやり直して上書きする。
  - `git clone` した人 → フォルダの中で以下を実行する。
    ```bash
    git pull origin claude/high-school-study-app-itcbb5
    ```
  - サーバーを立て直し、スマホ側は一度アプリを完全に閉じてから開き直してください
    (タスク一覧からスワイプで消してから再度開くと確実です)。

## トラブルシューティング

- **GitHub PagesのURLが404になる** → Settings→Pagesの設定直後は反映まで数分かかります。
  少し待ってから再読み込みしてください。Branchが `claude/high-school-study-app-itcbb5`
  になっているかも確認してください(`main` ブランチにはまだアプリ本体がありません)。
- **問題を増やしてもらったのに古いまま/真っ白になる** → ブラウザのキャッシュが原因のことが
  あります。iPhoneなら「設定」→「Safari」→「履歴とWebサイトデータを消去」、
  Androidなら「Chrome」→「設定」→「プライバシー」→「閲覧履歴データの削除」で
  一度キャッシュを消してから開き直してみてください(学習記録はlocalStorageの別領域に
  保存されていますが、心配な場合はキャッシュ削除の前にアプリ内の統計画面で正答率などを
  メモしておくと安心です)。
- **「ホーム画面に追加」が出てこない** → `file://` で直接開いていないか確認してください。
  `https://` または `http://`(サーバー経由)でアクセスしている必要があります。
- **スマホからPCのアプリにアクセスできない(方法B)** → PCとスマホが同じWi-Fiに
  つながっているか、PC側のファイアウォールがポート(8000番など)をブロックしていないか
  確認してください。

## 問題を追加・編集する

問題データはすべて `data.js` に入っています。科目ごとに配列があるので、
同じ形式でオブジェクトを追加するだけで問題を増やせます。

```js
{
  id: "kk-106",              // 科目内でユニークなID
  category: "漢字",          // 表示用のカテゴリ名
  question: "問題文",
  choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  answer: 0,                 // 正解のchoices配列内インデックス(0始まり)
  explanation: "解説文"
}
```

`id` を変えずに `question` や `choices` を編集すると、その問題の学習履歴(習得状況)は
引き継がれます。`id` を変えると新しい問題として扱われます。

## 学習記録の仕組み(簡易版Leitner方式)

- 各問題には「箱(box)」という習熟度レベル(0〜5)があります。
- 正解すると箱のレベルが1つ上がり、次に出題される(復習対象になる)までの間隔が長くなります
  (1日後 → 3日後 → 7日後 → 14日後 → 30日後)。
- 不正解になると箱はレベル0に戻り、「苦手」として記録され、次回以降の復習対象になります。
- 箱のレベルが4以上になった問題は「習得済み」として統計画面でカウントされます。
- 記録はすべて端末のlocalStorageに保存されます。ブラウザのデータを消去したり、
  別のブラウザ・別の端末で開いたりすると記録は引き継がれません(統計画面の
  「記録をリセット」も同じ仕組みで、ローカルのデータを消去します)。

## ファイル構成

```
index.html   画面のHTML(ホーム/クイズ/結果/統計の4画面をJSで切り替え)
style.css    スタイル
app.js       アプリのロジック(出題・採点・復習スケジューリング・画面遷移)
data.js      国語・数学・英語の問題データ
manifest.json PWA設定(アプリ名・アイコン・起動時の見た目)
sw.js        オフラインキャッシュ用のService Worker(ネットワーク優先・オフライン時はキャッシュにフォールバック)
icons/       ホーム画面アイコン用のPNG画像
```
